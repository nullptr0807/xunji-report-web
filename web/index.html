如何获取 API Key？
  1. 打开训记 App
  2. 进入「我」标签
  3. 点击「数据导出」
  4. 点击「申请 Key」，复制以 xjllm_ 开头的字符串

Key 等于你的训记账号访问凭证，请只粘贴到信任的网站。本服务的 Key 加密落盘，7 天后自动清除；不想再用可在训记客户端吊销。

每日 3 次配额：同一 API Key 24 小时内最多生成 3 份报告（含 AI 教练点评）， 避免无限制调用 LLM 烧穿成本。

数据保留 7 天：为了让你短期内重复生成报告时不必重复下载训练数据， 已下载的数据会在服务器上缓存 7 天，到期自动清除。

本服务仅将你的数据用于本次报告分析与展示， 不做任何形式的转售、模型训练、画像或商业化使用。

如果你不想再使用本服务，请在训记客户端吊销该 API Key。
